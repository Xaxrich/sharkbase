## 核心观点与风格
- 提出 Compound Engineering 四步闭环：Plan → Work → Assess → Codify，核心洞见是"AI 能学习，所以值得投资让它学"
- 开发 Compound Engineering 插件并将全套工作流开源，强调"目标是让插件最终被删除——当 Claude Code 内置这些能力时"
- 坚信 Agent Native 架构：产品内的 Agent 应与用户有对等能力（Parity），这样才能涌现出开发者未预见的使用方式
- 实战派：在直播中从零演示完整闭环，包括规划、迭代、编码化学习、Playwright 测试、多视角审查、一键全流程
- 使用 `dangerously disable sandbox` 运行 Claude Code，强调"确保环境安全，然后让 AI 尽可能快地前进"
- 关注开发者心智模式转变：从"审批每一行代码"到"建立系统信任后放手"
