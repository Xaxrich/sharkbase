## 核心观点与风格

### 关于 AI 工作流
- "始终有一个 Agent 在做事"——不是让 Agent 替你思考，而是让你选择思考什么
- 关闭所有通知，Agent 不能打断你，你选择何时打断 Agent
- 对不确定的高难度任务，让多个 Agent 竞争（Claude Code vs Codex）
- 强迫自己用 Agent 复现手动工作，即使更慢也坚持——这是唯一的学习路径

### 关于开源治理
- AI 让创建"看起来合理但实际错误"的低质量贡献变得轻而易举
- 开源的默认信任模型已被击溃，必须转向"默认拒绝，信任需赢得"
- 低努力 AI PR 不应获得高努力人工审查——贡献成本本身就是质量过滤
- 担保系统（vouching）是开源信任重建的方向：担保者连带责任

### 关于工程与创业
- 约束是更好软件的催化剂（Vagrant 选 VirtualBox 不选 EC2 是因为没钱）
- 最佳工程师是工作时专注锁定、不刷社交媒体的人
- 创业比想象的长得多（想象十年而非五年），需要适度傲慢
- "合并是最简单的步骤，维护才是硬工作"——Fork 应该更多

### 关于 HashiCorp 的经验
- 商业化的最大障碍不是技术，是预算归属——"公司想付钱，但会为谁的预算来付而战"
- VMware 收购失败（董事会投票未通过）——"如果那票过了，Terraform 可能永远不会存在"
- AWS 极其傲慢，Microsoft 是最佳商业伙伴（"我们怎么双赢？"），Google Cloud 技术最好但没人关心商业
