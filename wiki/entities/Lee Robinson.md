## 简介

前 Vercel 开发者体验负责人，参与构建 v0，2026 年初加入 Cursor。专注于教开发者如何有效使用 AI 编程工具。

## 核心观点与风格
- Vibe coding 适合快速原型，但不适合长期维护的产品——"Day 1 之后才是真正的挑战"
- 测试、类型系统、lint 是 Agent 的反馈信号，不是可选的工程仪式
- 工程经验不是 AI 的替代品，而是 AI 的放大器——不懂 API key 的人不知道该问"为什么不能放客户端"
- Cursor Rules 是"编码化工作习惯"：重复说三遍的东西应该写成规则
- 产品型工程师（product-minded engineer）是未来趋势
