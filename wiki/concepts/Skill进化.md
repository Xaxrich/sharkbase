# Skill进化

Skill 进化关注 Agent 如何把成功轨迹、失败修复、用户反馈、上下文资料和运行经验沉淀为可检索、可测试、可更新的技能资产。

## 要点

- 技能不是原始轨迹，也不是普通 memory，而是具有适用条件、步骤、边界和验证机制的能力单元。
- 技能可以来自强 Agent 轨迹、并行补丁合并、多用户交互、文档自博弈或运行时创建。
- 技能系统需要选择、使用、蒸馏、测试、淘汰和精炼机制，否则会变成噪声堆积的资料夹。
