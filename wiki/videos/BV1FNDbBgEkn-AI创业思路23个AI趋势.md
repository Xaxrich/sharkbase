# AI创业思路：23 个让我彻夜难眠的AI趋势

## 一句话摘要

系统梳理 AI 创业的 23 个趋势判断，从"一小时建公司"到 Agent 安全攻击面，核心论点是当前 12-24 个月是构建 AI 业务的非对称窗口期。

## 核心观点

- **一小时公司栈**：Vibe coding + 现有受众 = 一天内从想法到首个付费客户，传统 12 个月的时间线被压缩到一天
- **从 SaaS 到结果定价**：按座收费正在死亡，按结果付费（pay per result）正在崛起——因为 Agent 在做工作而非人在操作工具
- **垂直 AI > 垂直 SaaS**：垂直 SaaS 吃 IT 预算，垂直 AI 直接替代人力——TAM 是 10 倍差距
- **价值从执行迁移到判断**：AI 商品化了执行，稀缺的是创意判断、原创思维和专有数据
- **Agent 安全是新钓鱼**：Agent 注入攻击的潜在危害远超传统钓鱼，因为 Agent 有系统权限且自主决策

## 详细笔记

### 一小时公司与时间线压缩

传统建公司：招开发者（数月）→ 建 MVP（3 月）→ 上线 → 首收入（12 月）。2026 年新时间线：9AM 有想法 → 9:15 构建产品 → 9:45 完成产品 → 1PM 获首个客户。关键前提：你已有受众/邮件列表。无受众则获客仍是最大瓶颈。

### 环境业务（Ambient Businesses）

零或极低日常人力输入的业务——Agent 监控市场、识别机会、执行操作、处理客服。每隔几天检查一次即可。方向正确（箭头进步方向），但当前自主公司构建器产出的多为 AI slo。

### Agent 经济时间线

- 2009-2015：App Store 时代，人操作应用
- 2015-2024：API 经济，开发者连接 API
- 2025-2030：Agent 经济，Agent 发现并雇佣其他 Agent

Gartner 预测 2030 年 20% 商业为 Agent 对 Agent。市场预计达 520 亿美元。创业机会：**Agent 的 Glassdoor**——为 Agent 建立声誉和雇佣市场。

### Agent 雇佣 Agent

CEO Agent、Sales Agent、Dev Agent、Marketing Agent——用组织架构图思维取代"提示词完成工作"思维。Paperclip 展示了开源的 Agent 编排模式：Agent 启动子任务、完成后关闭，类似无服务器函数。

### 垂直 AI

YC 级别的大赛道（保险、房产、物流、养老、法律、医疗、销售）竞争激烈，应选择子利基作为切入点。关键洞察：**垂直 SaaS 吃 IT 预算，垂直 AI 直接吃人力预算**——后者是 10 倍大的 TAM。

无聊的金矿行业：仍在用电话和传真运转的领域——保险（30 年精算表）、法律、物流、养老、会计、建筑。越无聊越好，越细分越好，但避开高红 tape 领域（如政府销售）。

### SaaS 定价模式演变

座席制（$50/用户/月）→ 用量制 → 结果制（按交付结果付费）。原因：Agent 在做工作，不需要"座席"。SaaS 股票暴跌（从 12x 收入到 4x 收入）的两个原因：座席数减少 + 投资者担心 vibe code 替代方案。

Gartner 预测 2030 年 40% 企业 SaaS 转向结果定价。83% AI 原生 SaaS 已切换。创业机会：**帮传统 SaaS 转向结果定价**，或直接做结果定价创业。

### SaaS 墓地与稀缺翻转

**会死的**：通用 CRM、基础分析仪表盘、模板市场、调度工具、基础客服聊天机器人。

**会活的**：转向 Agent 的垂直工作流工具、基础设施和数据护城河。

**稀缺翻转**：被 AI 商品化的（通用内容、基础设计、数据录入、常规分析）→ 稀缺的（创意判断、人手工艺、物理体验、原创思维、专有数据）。**价值从执行迁移到判断**。

### 高级栈（Premium Stack）

- **最高级**：纯人手制作（Porsche 10% 人类制作广告活动；"无 AI"认证标签，类似有机食品）
- **高级**：AI 辅助、人主导（人的品味 + AI 速度）
- **商品**：纯 AI 服务（价格趋零的类别）

当数字内容无限且 AI 生成时，稀缺转移到**与他人共处的物理体验**——KTV、密室逃脱、沉浸式戏剧、共享办公、现场音乐。

### Founder-Agent Fit

从 Founder-Market Fit 到 Founder-Agent Fit：你能否编排一支 Agent 舰队朝目标前进？类比电影导演——不扛摄像机、不演戏、不写配乐，而是从演员（Agent）中榨取最佳表现。

### 幽灵团队组织架构

未来公司团队页：几个人类 + 一堆 AI Agent（销售 Agent、内容 Agent、客服 Agent）。Agent 可能被命名、有人设、有头像，最终能视频聊天和语音留言。持有公司形态会增多——你拥有一批 AI 原生 Agent 业务，由幽灵团队运营。

### 100 真粉丝

Kevin Kelly 的 1000 真粉丝在 AI 时代缩减为 100 真粉丝——因为 Agent 把成本砍到极低，100 人付费就是真正的生意。微型垄断模型：5000 受众 → 48 小时构建应用 → 100 客户 × $50/月 → $60K 利润/人 → 孵化多个。

### Agent 攻击面

这是视频中唯一让作者"害怕"的趋势。提示注入、投毒上下文窗口、恶意 MCP 服务、Agent 间操控、权限升级。**Agent 注入 vs 钓鱼**：2010 年钓鱼是骗人点链接（人判断力是防线），Agent 注入是骗 Agent 执行隐藏指令（Agent 自主性是漏洞）。Agent 有系统权限且自主决策，潜在危害远超钓鱼。Palo Alto Networks 已记录真实 Agent 注入攻击。创业机会：Agent 网络安全。

### Agent 权限栈

Agent 能访问什么（文件、邮件、日历、银行账户）、能记住什么（对话、个人/商业数据）、能做什么（发邮件、采购、改代码、删数据）、能分享什么。需要**季度 Agent 权限审计**，类似定期审查 App 授权。

### 非对称窗口期

构建成本≈0、Agent 做大部分工作、大量利基空白、受众价格被低估——不会永远持续。12 个月内竞争开始追赶，24 个月内窗口收窄。现在起步的人将开始积累数据/网络/品牌/信任护城河。**等待稳定下来是不成立的——这就是新常态。**

### Build in Public 仍然成立

反对"不要公开构建"的建议——如果你的关注者就是你的客户，公开构建让社区投票决定优先级、用户成为共建者、数天内交付更新，信任和分发复利增长。在"一键分叉业务"的世界里，让社区感到参与建设是重要的护城河。

## 我的评注

- **赞同**：结果定价取代座席制的判断准确。当 Agent 做工作而非人操作工具时，"座席"这个计价单位确实失去意义。Zendesk 已经按解决工单数收费，这不是预言而是正在发生的事。垂直 AI 替代人力预算 > IT 预算的 TAM 分析也是对的——这解释了为什么 Constellation Software 模式在 AI 时代有 10 倍放大效应。
- **质疑**："一小时公司"的说法把**构建**和**获客**混为一谈。视频承认需要"已有受众"，但这恰恰是 90% 创业者没有的。AI 把编码成本压到零，但没把分发成本压到零——和 [[AI原生商业模式]] 中对 Chat PRD 的质疑一致。100 真粉丝的数学只有在客单价足够高时才成立，$50/月 × 100 = $5000 MRR 对一线城市开发者并不算"真正生意"。
- **与 AI 工程实践的关联**：Agent 攻击面的讨论和 [[提示注入]] 概念高度相关。视频把 Agent 注入类比为新钓鱼，但低估了结构性差异——钓鱼需要人犯错（可以培训），Agent 注入利用的是架构缺陷（LLM 无法区分指令和数据），解法可能需要模型架构层面的根本改变。Agent 权限审计是务实的短期策略，但不是长期解。
