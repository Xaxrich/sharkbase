# Vibe Coding

## 定义
用自然语言（口语或文字）向 AI Agent 描述意图，由 Agent 生成代码并实现功能。开发者不再手写代码，而是"引导"Agent 工作。

## 为什么重要
Vibe Coding 不是"不用写代码的编码"，而是一种全新的软件构建范式。它重新定义了"谁可以构建软件"（非技术者也可以）和"什么是核心竞争力"（从编码能力转向引导 Agent 的能力——即上下文工程+品味判断+痛觉阈值）。2025年初被视为原型玩具，2026年初已进入生产环境。

## 我的判断
Vibe Coding 正在经历从"有争议的标签"到"被接受的实践"的转变。Ben Tossel 的洞察尤为关键：痛觉阈值才是真正的筛选器，不是技术能力。但 Yash 的反驳同样重要——如果你不对每一行代码负责，你就无法在出错时快速修复。两者并不矛盾：**引导 Agent 的能力需要你对系统有足够理解，但不需要你手写实现。**
