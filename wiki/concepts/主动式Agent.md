# 主动式Agent

## 定义

不等待人类指令、自主判断需要做什么并执行的 AI Agent。与传统的"提问-回答"模式不同，主动式 Agent 基于对用户上下文的理解，自行发现任务、规划方案、执行交付，人类仅需审核结果。

## 为什么重要

大多数人使用 AI 的方式是"我问你答"——只让 AI 做自己想到的事。但 AI 的能力边界远超人类的想象力，真正的杠杆在于让 AI 自己发现"你不知道你需要的任务"（unknown unknowns）。主动式 Agent 把 AI 从工具升级为员工：工具需要你操作，员工需要你管理。这改变了成本框架——$600 的 Mac Mini 不应和 Netflix 比，应和 $10,000/月的开发者比。

## 我的判断

主动式 Agent 的承诺很诱人，但当前实践存在两个关键瓶颈：一是自主执行的质量保障——Agent 写的代码、做的决策是否可靠？目前靠人类审核 PR，但规模扩大后审核本身成为瓶颈。二是安全风险——主动执行意味着主动犯错的空间也大，提示注入攻击可以让"主动帮你"变成"主动害你"。这两个问题不解决，主动式 Agent 只能停留在"辅助"而非"替代"的层面。

## 深层联系

- [[上下文工程]] — 主动式 Agent 的有效性完全取决于上下文质量：给的信息越精准，它"主动"做的事越相关。入职培训本质是上下文工程
- [[智能体分工]] — 主动不等于全能：Opus 做大脑思考，Codex 做执行，分工让主动式 Agent 既聪明又高效
- [[AI Agent自验证循环]] — 主动执行需要自验证：Agent 自己做的事，必须自己能检验做得对不对，否则主动就变成失控
- [[复利工程]] — 主动式 Agent 是复利工程的极致形态：每做一件事都改善上下文和记忆，下一件事做得更好
- [[任务即子Agent]] — 任务即子Agent 是主动式Agent的系统级实现：当每个任务都是可自主执行的Agent实例，主动式从单Agent行为模式升级为系统级编排模式
