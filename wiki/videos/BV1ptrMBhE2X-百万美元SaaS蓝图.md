# 从零开始构建一个百万美元SaaS的蓝图

## 一句话摘要

六个经过实战验证的 SaaS 获客剧本，每个都附带真实案例和可复制的执行细节。

## 核心观点

- **获客才是真正的难题**：人人都会 vibe code 一个产品，但没人知道怎么获客——营销能力比产品本身更稀缺
- **内容销售的要义是"克制"**：越不明显地推销，转化越高——信任建立后，越少提产品，人们越想要
- **当下最大的营销红利是 AI 搜索**：ChatGPT/Perplexity 推荐的转化率是 Google 的 4-17 倍，窗口期就在未来六个月
- **注意力与付费意愿常常错位**：高关注度产品（如验证收入截图工具）适合广告变现而非订阅；高价值产品才适合付费广告获客
- **定价的核心手法是人为制造稀缺**：限制早期用户名额、阶梯涨价，让需求始终略高于供给

## 详细笔记

### 嘉宾背景

Rob Hoffman，经营三家盈利的 bootstrap SaaS：Contact So（SEO 工具，$300K MRR）、Mentions So（$20K MRR）、Clio So（AI 社交内容生成，$61K MRR）。两个软件公司 + 一家 SEO 代理机构。

### 剧本一：等待名单策略（Waitlist Strategy）

**案例**：Clio So（$61K MRR，53 天达成）、Mentions So（$20K MRR，30 天达成）

核心流程：内容 → 邮件列表 → 网络研讨会 → 迭代 → 再发布

1. **创作"隐含销售"内容**
   - 不要在帖子里硬推产品，而是分享目标受众关心的知识，在文中某一条要点里轻描淡写地提及工具
   - CTA 可以放在评论区、编辑后追加、或帖子末尾——核心是让读者不觉得被推销
   - 借用名人/权威的图片吸引注意力，发布带争议性的观点引发讨论
   - Rob 的合伙人 Jake 的做法更极端：帖子完全不提产品，读者必须主动去他主页才能发现他在卖什么——但 Jake 驱动了公司大部分收入

2. **启动限量早期 beta**
   - 建立等待名单后，向前 500 名用户提供终身折扣（Clio 定价 $99，早期价 $59）
   - 用一系列邮件培养期待感：每封邮件用不同策略（教育、启发、好奇心），配合稀缺性和紧迫感
   - 邮件风格：易扫读、叙事感、不像推销信
   - 网络研讨会作为补充，转化还在犹豫的用户
   - 注意：AI 产品卖终身访问要算清 token 成本，避免卖 $59 但每月花几百美元服务一个用户

3. **用早期用户迭代**
   - 三个创始人每人至少与 50 位客户通话，日历排满
   - 目标：找到最有价值的功能、发现 bug、为第二次 beta 做准备

4. **重复发布流程**
   - 第二批 beta 涨价至 $79，继续内容→邮件→研讨会流程
   - 公开上线时定价 $99

### 剧本二：乘风策略（Wave Surfer Strategy）

**案例**：Trust MRR（$24K MRR，约 30 天达成）

1. **找到正在爆发的趋势**
   - 不是创造需求，而是找到已有的注意力，然后搭便车
   - Peter Levels 发推抱怨 X 上假 MRR 截图泛滥 → Mark Lou 在 48 小时内上线 Trust MRR（验证收入的数据库）

2. **极速发布，快速放弃**
   - Mark 的原话："Ship fast, but also quit fast if it's not working"
   - 在 X 上，Quote Retweet 目前表现极好——找到病毒推文，引用转发并附上自己的解决方案

3. **将病毒性植入产品本身**
   - Trust MRR 的核心功能就是生成可分享的验证收入截图——产品天然适配社交传播

4. **注意力产品用广告变现，不用订阅**
   - 高注意力 ≠ 高付费意愿。大量人觉得有趣，但不愿付费
   - 解决方案：卖广告位。Trust MRR 全免费，收入来自企业买广告触达创业者受众
   - 类似案例：Peter Levels 的飞行游戏，靠广告第一个月赚 $100K
   - 广告位也用稀缺性：早期广告主低价，名额有限

### 剧本三：语言套利策略（Language Arbitrage Strategy）

**案例**：Teach Easy（$65K MRR）——法语版的 Teachable/Kajabi

1. **把已验证的英文 SaaS 做成另一种语言/地区版本**
   - 不只是翻译，而是全面本土化：法语界面、法国国旗、"Made in France"标识、法国式幽默
   - 身份认同是购买驱动力——人们更愿意买本国产品
   - 类似先例：Rocket Internet 把 Airbnb 等模式搬到欧洲各国，甚至后来卖回给原公司

2. **非英语 SEO 是"简单模式"**
   - 法语关键词的竞争难度极低，关键词难度面板几乎全是绿色
   - Teach Easy 的创始人确认 SEO 是其第一大获客渠道
   - 非英语 SEO 类似英文 SEO 的 2010 年代早期——蓝海

### 剧本四：AI 搜索策略（AI Search Strategy）

**案例**：Tally（无代码表单构建器，$338K MRR）

1. **当前 OP 营销渠道是 AI 搜索**
   - OP = Overpowered，游戏术语，意为"过于强大"
   - 2007 年的 OP 渠道是 Facebook，2017 年是 TikTok，现在和未来六个月是 AI 搜索

2. **重仓 80/20 的 SEO 页面**
   - 只做最高转化率的页面类型：Alternatives 页面（"X 的替代方案"）、Versus 页面（"A vs B"）、底部漏斗博客（"最佳免费表单构建器"）
   - 页面必须全面、高质量——不是生成几百篇薄内容，而是精心打磨几篇权威页面
   - Tally 被引用最多的页面正好就是这几类

3. **AI 搜索流量的转化率远超 Google**
   - Google 搜索：用户面对 10 个蓝色链接
   - ChatGPT/Perplexity：用户只看到 2-4 个推荐
   - 信任度差异：人们对 ChatGPT 的信任远超 Google
   - 实测数据：来自 ChatGPT 的流量转化率是 Google 的 4-17 倍

### 剧本五：信号搜索策略（Signal Search Strategy）

**案例**：Local Rank（本地 SEO 工具，$47K MRR）

1. **用一个功能测试市场**
   - Local Rank 有很多功能，但首发只用热力图一个功能
   - 可以快速发布 5-10 个功能，看哪个获得最多关注

2. **YouTube 是被低估的获客渠道**
   - Local Rank 首日 $5K MRR，80-90% 来自 YouTube
   - YouTube 发布视频的观看量只有 X 推文的 1/10，但驱动了 80% 的销售
   - 不需要精良制作——Loom 录屏 + 粗糙缩略图就够了
   - 信任建立：YouTube 视频建立的信任度和转化率远超 X 帖子

3. **封顶早期用户，多次涨价**
   - 人为限制供给 → 需求 > 供给 → 价格上涨空间
   - Local Rank 涨价四次

4. **测试企业级套餐**
   - 最低 $20-40/月 → 企业计划 $400/月（10 倍）→ 顶级 $1600/月（33 倍）
   - 从 $5K 到 $20K MRR，仅靠引入企业套餐
   - 少量高付费客户贡献大量收入

5. **无人设账号也能获客**
   - 用无个人身份的 X/LinkedIn 账号发内容，从零起步
   - 关键在内容质量，不在粉丝数量——一条爆款内容可以驱动几十万美元收入
   - 回复 → 自动私信送手册 → 引导至产品（reply-to-DM 策略）

### 剧本六：高客单价广告策略（High Ticket Ad Strategy）

**案例**：Mail Scale（B2B 冷邮件工具，$10K MRR）

1. **低客单价产品无法通过付费广告盈利获客**
   - 月费 $50 以下的产品，获客成本很容易超过客户生命周期价值
   - 需要有高客单价套餐（$300+）才能让广告投放回本
   - 替代方案：自清偿漏斗（广告 → 免费研讨会/低价信息产品 → 逐步升阶到 SaaS 订阅 → 企业套餐）

2. **创建 VSL（Video Sales Letter）预热**
   - 高质量视频 + 落地页，替代高门槛的 1 对 1 通话
   - 看视频的门槛远低于约电话
   - VSL 不一定看起来像 ClickFunnels 垃圾页面——可以是精致的企业风

3. **用 AIDA 框架制作广告素材**
   - Attention → Interest → Desire → Action
   - 用 ChatGPT 图像生成制作广告图（低成本）
   - 研究竞争对手的 Meta 广告库，关注运行时间最长的广告——运行越久说明越赚钱
   - Mail Scale 花了 $10K 测试 5-10 个广告才稳定地以 <$1000 获客

4. **规模化：验证后招聘销售团队**

## 我的评注

- **赞同**："隐含销售"的洞察非常实用。独立开发者最常见的错误就是刚做出来就到处硬推，反而引起反感。克制销售、先给价值的策略值得每个产品人实践。
- **赞同**：AI 搜索作为获客渠道的分析很有前瞻性。ChatGPT 推荐只有 2-4 个结果 vs Google 的 10 个蓝色链接，这种注意力集中度的差异确实会导致转化率数量级提升。
- **质疑**：视频基本假设"产品本身不是问题，获客才是"，但现实中大量独立开发者的产品确实没人需要。六个剧本都是获客技巧，几乎没有涉及需求验证——如果方向错了，获客效率再高也是浪费。
- **质疑**：案例中的创始人大多已有受众基础或多次创业经验（Rob 本人有三家 SaaS，Mark 有 23 万粉丝），"任何人都能做"的说法忽略了积累的复利效应。无脸账号从零起步确实可行，但视频低估了内容能力的培养周期。
- **关联**：与 [[AI评估体系]] 形成呼应——视频反复提到 ChatGPT 推荐的信任度远超 Google，这本质上是 AI 作为判断权威的现象。AI 搜索推荐正在成为新的"入口"，这直接影响 SaaS 产品的分发逻辑。
