# Vibe Coding实践：101款你可以Vibe Code的AI应用

## 一句话摘要

系统性地梳理了101个可由Vibe Coding构建的AI应用方向，并给出从创意到部署的五步实战框架。

## 核心观点

- 编程没有过时，但现在可以用Vibe Coding（无传统编码）构建很多类型的应用
- 构建AI应用有可复用的五步框架：Meta Prompt → PRP → 实现 → 调试 → 部署
- AI应用可以按七类划分：数据管理、硬件Agent、仪表盘、聊天助手、学习Agent、多模态、自动化与宏
- 好的AI应用始于对"为谁解决什么问题"的清晰定义，而非直接写代码
- 调试是增量循环的过程——实现一个功能，调试，再实现下一个

## 详细笔记

### 五步构建框架

1. **Meta Prompt（元提示词）**：在创意阶段强制思考应用目的、目标用户、核心功能、市场定位。如果自己都不清楚要建什么，别指望AI能猜对。
2. **Product Requirements Prompt（产品需求提示词）**：Meta Prompt的产出物，类似产品经理的PRD，包含产品描述和所有核心功能定义。后续AI辅助编码都以此为参照。
3. **实现**：基于PRP让AI辅助编码，逐步实现功能。可在此过程中调整UI和功能细节。
4. **调试**：增量式循环——实现一个功能后调试，截图报错让AI修复，再实现下一个。这是最耗时的阶段。
5. **部署**：安全、版本控制、托管等。Vibe Coding工具通常自带部署选项。

### 七类AI应用

#### 一、数据管理类

核心能力：将非结构化原始数据转化为可搜索、可查询、可摘要的结构化知识。

典型工作流：批量导入 → AI转录/标注/索引 → 存入数据库 → 用户查询 → AI检索并返回结果

- **视频内容搜索库**：批量导入视频，AI转录索引，用户按语义搜索特定片段
- **跨企业搜索**：连接Notion、Slack、Google Drive等多源数据，统一搜索入口
- **音频转录搜索**：对播客、会议录音做精准检索
- **内部文档语义搜索**：企业知识库的语义级检索
- **学习资料整理器**：上传PDF和笔记，AI按主题或问答形式重组
- **数据清洗**：清理混乱的Excel文件，输出整洁版本
- **图像分类标注**：上传图片自动分类（如花卉品种）并添加标注标签
- **医疗影像标注**：标注风险等级，转交医疗人员
- **语音数据交互**：直接用语音与数据对话
- **报告自动化**：自动生成并分发内部/外部报告

#### 二、硬件/Agent类

核心能力：AI与物理世界交互，处理实时传感器数据，检测异常并触发行动。

典型工作流：实时数据采集 → AI分析检测异常 → 决策触发行动 → 汇总报告

- **交通监控**：摄像头+传感器，检测事故后自动报警、调节信号灯
- **交通流量预测**：历史+实时数据预测路况
- **违停检测**：识别违规停放车辆
- **人群管理**：检测人流瓶颈，引导疏导
- **空气/噪音污染监测**：城市级传感器网络，辅助城市规划
- **安防摄像头**：物体识别、隐私滤镜（自动模糊人脸/车牌）、异常检测
- **智能家居**：能耗异常检测、语音控制家电、智能冰箱补货提醒、设备故障预警
- **可穿戴设备聚合器**：整合Apple Health等多源数据，给出个性化健康建议
- **睡眠与饮食**：基于生活方式生成个性化方案
- **智能辅助设备**：AI助听器、智能眼镜、触觉传感器
- **车载AI**：主动提醒维护、驾驶行为分析
- **车队监控**：无人机/车辆编队模式监控

#### 三、AI增强仪表盘类

核心能力：实时数据可视化 + AI洞察，用户可下钻细节。

- **财务仪表盘**：汇总银行账单，分析支出，生成洞察（如"咖啡占月支出30%"），支持WhatsApp/语音播报
- **趋势监控**：追踪市场动态、销售预测、行业新闻
- **KPI追踪器**：内部指标可视化，"不被追踪的事就不会被完成"
- **支出异常仪表盘**：实时检测异常消费模式
- **竞品价格抓取**：自动调价建议
- **销售CRM仪表盘**：客户关系管理可视化
- **资源分配追踪**：项目预算是否花在正确的地方
- **错误优先级排序**：哪些bug最值得先修
- **社交媒体监控**：实时舆情追踪

#### 四、聊天助手类

核心能力：理解用户意图 → 检索信息/执行操作 → 返回结果 → 记录日志

强调与用户的沟通能力和行动执行能力，Agent是助手的一个子类。

- **会计助手**：对接QuickBooks等API，语音记账
- **法律助手**：监控法规变化，提醒合规风险
- **报销助手**：拍照收据自动归档
- **CFO Agent**：现金流预测、跑道预警、薪资风险提醒
- **医疗保险助手**：理赔全流程自动化
- **福利导航**：帮员工发现未使用的公司福利
- **用药指导**：解释处方、辅助续方
- **健康档案整理**：跨医院记录统一管理
- **客服Agent**：处理复杂问题、跟进回访
- **IT帮助台**：技术问题排查
- **预约助手**：打电话预订餐厅/挂号
- **购物助手**：个性化商品推荐
- **订阅管理**：追踪所有订阅，避免浪费
- **退货助手**：自动化繁琐的退货流程
- **账单谈判**：自动协商水电网络费

#### 五、学习Agent类

核心能力：用户输入 → AI评估打分 → 反馈建议 → 强化练习 → 进度追踪

与聊天助手的区别：更强调学习循环和用户进步的反馈机制。

- **关系教练**：分析冲突对话，建议更好表达方式，通过角色扮演强化
- **绘画教练**：上传草图获实时改进建议
- **运动教练**：上传挥杆视频，AI分析动作并建议改进
- **演讲教练**：录制演讲获实时点评
- **语言学习**：实时对话练习和纠正
- **职业教练**：AI模拟面试，降低真人mock成本

#### 六、多模态类

核心能力：混合文本、图像、视频、音频等模态，进行创作和转换。

- **幻灯片生成器**：输入主题 → AI生成初稿 → 用户迭代调整 → 导出PPT/PDF
- **新闻/社媒内容创作**：从选题到发布的工作流
- **视频解说**：AI对视频内容实时评论（如足球比赛解说）
- **跨模态转换**：视频→文本、文本→图像、图像→视频
- **多媒体故事生成**：混合文字、图片、音频的交互式叙事

#### 七、自动化与宏

核心能力：触发器 → AI处理 → 执行动作 → 记录日志。目标是尽量减少人工干预。

分两类：

**云端自动化：**
- 客户反馈分类（自动标记紧急程度，提交工单）
- 邮件/文档摘要
- 发票处理
- 会议调度
- 销售线索挖掘
- 代码审查助手
- 合规检查器
- CRM笔记同步
- 跨工具数据同步

**本地宏：**
- 文件整理器（下载文件自动归类重命名）
- 剪贴板助手（粘贴时自动扩展文本）
- 语音控制电脑
- 电子表格宏（自动填入常用公式）
- 截图分析标注
- 本地文件搜索
- 照片标签器
- 演示文稿助手
- 安全扫描（上传前检查是否泄露密钥）

## 我的评注

- **赞同**：五步框架（Meta Prompt → PRP → 实现 → 调试 → 部署）把"从想法到产品"拆解得清晰可执行，Meta Prompt强调"自己先想清楚再让AI动手"是对的——模糊需求是Vibe Coding最大的坑。
- **赞同**：七类分类法有实用价值，尤其是将"自动化与宏"单独列出，很多人低估了日常重复任务的自动化潜力。
- **质疑**：101个应用方向虽然覆盖面广，但大量只是"用AI做X"的简单映射，缺乏对可行性边界的讨论。比如硬件Agent类应用（交通监控、医疗影像）涉及安全合规，并非Vibe Coding能轻松搞定的。
- **质疑**：视频没有讨论这些应用的实际落地难度差异——一个文件整理宏和一个CFO Agent之间的复杂度差距是数量级的，但被并列呈现，容易给新手造成"都很容易做"的错觉。
- **关联**：五步框架与[[AI驱动的产品工作流]]高度相关，但更偏实操层面。Meta Prompt本质上是把产品思维前置到提示词中，和[[Vibe Coding]]的核心主张一致——用自然语言替代代码作为表达媒介。
