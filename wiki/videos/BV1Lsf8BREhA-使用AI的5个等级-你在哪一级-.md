# 使用AI的5个等级，你在哪一级？

## 一句话摘要

提出从"用AI搜索"到"AI代理运行生活"的五级进阶框架，核心论点是大部分价值集中在前三级，且四级可在一周内达成。

## 核心观点

- AI使用能力可以分为5个递进等级：日常问答 → 日常工作 → 原型开发 → 构建应用 → 个人代理
- 80%的AI价值来自第二级（语音听写+会议笔记+项目上下文），而非高阶用法
- 原型应先于规格书和设计稿——代码现在比文档更容易创建
- Vibe Coding的本质是把AI当实习生管理：你负责规划和反馈，AI负责执行
- 最终交互界面不是按钮和菜单，而是躺在床上给AI代理发模糊指令

## 详细笔记

### 第一级：AI用于日常问答

99%的人停留在此级——用ChatGPT替代Google搜索。修马桶、问菜谱、查常识。这是起点但远非终点。

### 第二级：AI用于日常工作

作者认为这是价值最大的级别，三个关键实践：

1. **语音听写**：用WhisperFlow等工具，按键即语音输入，AI自动格式化。比打字快得多，且AI擅长理解意识流。
2. **AI会议笔记**：用Granola等工具自动记会议笔记，可随时追问"刚才讨论了什么"。不添加日历机器人，体验干净。
3. **AI项目**：在ChatGPT/Claude中建立项目（Projects），预置上下文（家庭偏好、工作背景），让AI基于你的具体情况给出建议。

作者甚至帮60多岁的父母也搭建了这套系统。

### 第三级：AI用于原型开发

颠覆传统瀑布流程的方式：

- **传统**：写规格书 → 交付设计师 → 交付工程师
- **新方式**：用Replit/Google AI Studio先做原型 → 快速收集反馈 → 迭代确认方向后再写规格书处理边界情况

核心洞察：**代码现在比任何文档、幻灯片或设计稿都更容易创建**。原型让利益相关者能"玩"你的想法，而不是看静态文档。作者从未见过领导更喜欢看文档而非操作原型。

### 第四级：AI用于构建应用

Vibe Coding的实践级。作者6个月内构建了4+个应用：

- 模拟Oregon Trail的"Builder Trail"游戏
- 个人网站（集成Substack、彩蛋）
- Board Game Geek数据的浏览器界面
- 像素风太空射击游戏（2小时完成）

#### 如何开始

1. **不知道建什么** → 告诉AI你的问题，让它建议能帮你省时间的应用；或直接建一个游戏
2. **先做规划** → 让AI制定3个里程碑的计划。现实是：你花大部分时间写英文文档做规划，AI做编码
3. **把自己当管理者，AI当实习生** → 给反馈、截屏bug、给方向、保持耐心

#### 工具选择

- **新手**：Replit（全栈平台，内置安全防护，防止API密钥泄露）
- **要更多控制**：Cursor（最流行的AI IDE，但需配置GitHub+Vercel部署）
- **追求极致**：Claude Code终端/Codex，多终端窗口并行开发多个功能

#### 进阶路径的讽刺

从网页界面接受AI建议 → YOLO模式（AI自主修改） → 单终端Claude Code → 多终端并行 → 一个AI编排多个AI Agent。最顶尖的工程师已在Figure 8阶段。

### 第五级：AI作为个人代理

终极形态：躺在床上，用语音或文字给AI代理模糊指令，让它替你做事。

#### 三个实例

1. **Karen**：构建了"复合工程系统"——自定义Claude Code的skills和命令，一条`lfg`命令自动执行全流程，离开2-3小时后回来获得完整产品
2. **Three**：用Claude Code + Obsidian管理生活和业务，三层上下文文件让AI生成每日待办、博客文章、任务管理
3. **Naeson**：给OpenAI Bot开设独立X账号和Stripe/GitHub API密钥，一周内自主创收$3,500（卖PDF）+ $37,000加密货币交易费

## 我的评注

- **赞同**：五级框架的递进逻辑清晰，"80%价值在前两级"的判断诚实且反直觉——大多数人高估了高阶用法的价值而低估了基础设置的杠杆效应。语音听写+项目上下文的组合确实是低门槛高回报的实践。
- **赞同**：原型先于规格书的论点有力。不是否认文档价值，而是指出在快速验证阶段，可交互原型的信息密度远超静态文档。
- **质疑**：第五级的案例（特别是Naeson的$37,000加密货币收入）有明显的幸存者偏差。视频没有讨论AI代理自主操作带来的风险——银行账户访问权、自主发布内容、自主交易——这些失败案例被选择性忽略了。
- **质疑**：工具推荐有赞助倾向（Granola是赞助商），且"一周到四级"的承诺过于乐观——对于没有技术背景的人，Replit的部署和调试仍然是实质性障碍。
- **关联**：五级框架与[[Vibe Coding]]的核心主张一致——编程正在从"写代码"变成"用自然语言指挥AI"。与[[AI驱动的产品工作流]]的直接联系：第三级"原型优先"本质上就是AI驱动的产品开发流程。与[[主动式Agent]]的关联：第五级描述的正是从被动问答到主动执行的跃迁。
