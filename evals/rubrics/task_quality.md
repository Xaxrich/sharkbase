# Practice Task Quality Rubric

## 评分维度

| 维度 | 1分 | 5分 |
|------|-----|-----|
| 可执行性 | 描述模糊，不知道做什么 | 步骤明确，输入输出产物清晰 |
| 验收标准 | 无标准或标准模糊 | 有可检验的通过/不通过标准 |
| 能力关联 | 不知训练什么能力 | 明确归位到能力地图二级能力 |
| 难度匹配 | 太简单或太难 | 符合目标掌握等级 |
| 失败预判 | 未提及常见失败 | 列出常见失败和规避方法 |
| 可复盘 | 无复盘结构 | 有复盘字段且能沉淀经验 |

## 通过标准

- 可执行性 >= 4
- 验收标准 >= 4
- 能力关联 >= 3
- 总分 >= 22
