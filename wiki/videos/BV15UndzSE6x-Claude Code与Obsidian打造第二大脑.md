# Claude Code + Obsidian：打造第二大脑

## 一句话摘要

Noah Brier 展示了如何将 Claude Code 运行在 Obsidian 知识库根目录，配合家庭服务器和手机终端，构建一个能读、能问、能回顾的真正第二大脑——核心洞见是 AI 的阅读能力远比写作能力更有用。

## 核心观点

- **AI 的阅读能力比写作能力更被低估**——我们每天思考的频率远高于产出成品的频率，让 AI 帮你读和整理比让它帮你写更有日常价值
- **思考模式 vs 写作模式**——必须显式告诉 AI "不要写，只帮我思考"，否则它总想直接产出成品；这个区分是用好 AI 的关键
- **概率性计算需要新直觉**——传统软件集成的经验在 AI 时代被 180 度翻转，必须通过使用来建立新直觉，就像学骑自行车一样无法靠讲解获得
- **AI 是组织的"缝隙渗透者"**——不需要统一工具和流程，AI 能适配任何数据结构的特性让它可以嵌入组织的每个角落，绕过官僚体系
- **手机可以成为深度工作的设备**——通过家庭服务器 + VPN + 终端 App，Claude Code 让手机上的思考和代码修改变得可行

## 详细笔记

### 整体架构

Noah Brier 的核心配置：
- **Claude Code 运行在 Obsidian 知识库根目录**（不是子文件夹），使其能访问全部约 1500 条笔记
- **Obsidian 文件夹用 PARA 方法组织**（Projects/Areas/Resources/Archive）
- **通过 Git 同步到私有 GitHub 仓库**，实现多设备访问
- **在 Obsidian 中添加 package.json**，可以定义自定义命令供 Claude Code 调用

### 思考工作流：以演讲准备为例

Noah 正在准备一场关于"AI 与官僚主义"的演讲，展示了完整工作流：

1. **收集阶段**：在 Obsidian 中创建项目文件夹，包含：
   - `chats/` — 从 ChatGPT/Claude/Grok 等处的对话全文（用 Obsidian Web Clipper 保存）
   - `research/` — 文章、PDF 等研究材料
   - `daily progress/` — AI 每天回顾当天笔记，帮助梳理进展
   - 各种零散笔记

2. **启动阶段**：让 Claude Code 扫描整个知识库，找出与演讲主题相关的已有笔记，复制到项目的 research 文件夹

3. **思考模式**：切换到"思考伙伴"子代理（subagent），明确指令包括：
   - "不要尝试写任何东西"
   - "不要创建大纲或版本"
   - "只收集和组织素材"
   - "问我问题，帮我思考"

4. **每日回顾**：离开后回来时，直接问"帮我回顾过去三天的研究进展"，Claude Code 读取所有相关文件并给出摘要

### 核心哲学：阅读 > 写作

Noah 反复强调：AI 社区过度关注生成能力，忽视了阅读和理解能力。我们产成品的频率远低于思考的频率。一个好的 AI 工作流应该优先利用它的阅读能力——扫描、搜索、整理、联系——而不是急着让它写作。

### 演讲核心论点："官僚主义即位置编码"

Noah 正在发展一个将 Transformer 和组织理论联系起来的类比：
- **官僚主义曾是创新**——它为大规模组织提供了层级和结构
- **Transformer 从序列模型走向并行模型**——突破了 RNN 的瓶颈
- **官僚主义类似于位置编码**——为信息提供位置和结构
- **AI 的独特之处**：不像以往技术要求你采用新结构，AI 可以适配任何现有结构（他称之为"Thomas's English Muffin 理论"——AI 渗入每个缝隙）

### 隐性代码共享

Noah 描述了 Every 内部的一个实践：不同产品使用不同技术栈，但 AI 可以让一个开发者阅读另一个产品的代码并用自己的方式重新实现，无需抽象成共享库。这比传统的"抽象-模块化-统一"路径高效得多。

### 手机端设置

这是整套系统的延伸：
- **硬件**：地下室的一台 Mini PC
- **网络**：Tailscale VPN，只通过 VPN 可访问
- **终端**：手机上用 Termius（终端 App）连接
- **流程**：通过 Git 同步 Obsidian → 在 Mini PC 上运行 Claude Code → 手机终端访问
- **实际用途**：在外面用手机做演讲研究、修复网站链接、推送代码 PR

### 语音模式用于研究

Noah 认为 Grok 的语音模式是目前最好的（优于 ChatGPT 和 Gemini），核心原因是工具调用能力更强。他在开车时用 Grok 语音模式进行深度研究——从 Walter Benjamin 的艺术复制理论到 Transformer 的自注意力机制。

### 关于直觉与教育

- **新范式需要新直觉**：引用 Veritasium 的自行车视频——你无法向孩子解释如何骑车，他们必须自己感受
- **量子物理的类比**（Philip Ball《Beyond Weird》）：问题不在物理本身，而在我们缺乏描述非确定性世界的词汇
- **AI 同样如此**：概率性计算机要求我们建立全新的操作直觉
- **教育观点**：AI 暴露了教育体系的缺陷——过度注重测试而忽视思考和学习的内在动机
- **媒体素养**：Tim Harford 的《The Truth Detective》（儿童版）是他推荐的核心素养读物，核心原则是"让你感觉良好的信息应该更受怀疑"（brain guard）

### 实用工具生态

- **Claude Code + Obsidian 附件重命名器**：用 Gemini Flash 识别 PDF/图片内容并重命名，更新所有 wikilink
- **Claude Code 系统配置助手**：专门的项目帮助配置 Linux/Mac 环境，记住所有偏好设置
- **Claude Code + GitHub MCP**：跨项目复用代码方案

## 我的评注

- **赞同**：思考模式 vs 写作模式的区分极其精准。大多数人的挫折正来自于 AI 总想"帮"你写，而你需要的是它帮你想。把"不要写"写进系统提示是实操层面的关键技巧。
- **赞同**：让 Claude Code 运行在知识库根目录而非项目子目录，这一架构选择释放了全文检索的能力，是"第二大脑"真正成立的条件。
- **质疑**："官僚主义即位置编码"这个类比目前更多是有趣的直觉而非严谨的论证。位置编码是为序列中的 token 提供位置信息，官僚主义提供的是决策权限和流程控制——两者功能不同，类比需要更多打磨才能成立。
- **关联**：视频中的"隐性代码共享"——不抽象共享库，靠 AI 阅读理解后重新实现——与知识库的"概念页综合式更新"有深层共振。两者都放弃了"统一抽象"的路径，转而让智能体在每次需要时重新理解和重组。这是一种反抽象主义的实践智慧。
- **待深入**：Noah 提到的"每日进展回顾"和"回顾过去三天研究"的工作流，本质上是让 AI 充当记忆的外部索引。这个模式是否可以系统化——比如自动生成每日知识摘要、检测思维方向偏移？
