# AI 原生产品系统架构师能力地图

## 一级能力

1. **商业问题与机会判断** — 识别值得解决的问题，判断市场窗口与商业模式可行性
2. **知识输入与研究综合** — 高效采集、蒸馏、综合多源信息，形成可操作判断
3. **产品定义与规格设计** — 把模糊需求转成可执行 Spec，设计交互与信息架构
4. **AI 辅助开发与 Agent 调度** — 用 AI 工具链加速开发，调度 Agent 完成编码任务
5. **Agent 架构与工作流设计** — 设计 Agent 系统的分工、上下文、工具、反馈闭环
6. **评估体系与质量校准** — 建立评估标准，用 LLM-as-Judge / 人工 / 代码评估对齐质量
7. **上线验证与增长反馈** — 从 MVP 到上线，用真实数据验证假设并迭代
8. **资产化与方法论输出** — 把经验沉淀为 SOP / Prompt / Skill / 模板等可复用资产
9. **自我操作系统** — 用个人 OS 管理目标、注意力、知识、决策，让 AI 对齐你的意图
