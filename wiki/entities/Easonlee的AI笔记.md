## 核心观点与风格
- 强调 AI 是"可培训的初级同事"——需要给护栏、给上下文、给脚本，而非放手让它自由发挥
- 关注 AI 在营销领域的落地（数据分析、A/B 测试、内容生成），而非纯技术讨论
- 关注从原型到生产应用的工程化路径，强调安全性（RLS、数据库迁移）不可忽视
- 实战驱动：每个概念都有现场演示，从 UTM 生成器到推文转长文
- 偏好翻译英文 AI 播客/访谈，内容偏开发者教育与实操指南
- 关注 AI 评估的实战方法——不只是理论，而是 PM 真正在电子表格里标注、辩论、迭代的脏活；强调"看 trace"比任何自动化评分都更有价值
- 擅长展示工具组合工作流（NotebookLM + Deep Research + Firebase Studio），从研究到产品的全链路演示
- 关注 AI 编码 Agent 的生态格局和分工策略——不迷信单一工具，而是根据任务特性选择最合适的 Agent
- 关注 Vibe Coding 时代的应用设计差异化——在编码零门槛的环境下，微交互、吉祥物、Widget 等设计细节成为脱颖而出的关键
- 关注多模型同题竞速的实证方法——通过控制变量实测不同模型的设计深度、产品思维和功能完整性，而非依赖基准测试排名
- 关注 SaaS 独立开发者的实战获客方法——六个剧本从等待名单到 AI 搜索优化，强调获客能力比产品本身更稀缺
- 关注 AI 编码工具的实操技巧组合——不迷信单一工具，双工具并行 + 模型差异化配置 + 六条微操技巧（plan mode、ultrathink、后台任务、MCP、代码审查、语音输入）
- 关注规范驱动开发作为 vibe coding 的工程化替代——结构化需求→设计→执行工作流、EARS 格式与属性测试的贯穿线、MCP 在规范流程各阶段的用法
- 关注AI在产品管理全流程的实战应用——战略文档迭代、原型优先开发、个人OS构建，强调"每个人都在构建自己的个人AI产品"
- 关注 AI 产品设计工作流的实战重构——Claude Co vs Claude Code 分工、多源洞察提炼自动化、"引导 vs 自由"的 AI 产品 UI 设计张力、内部 dogfooding 文化
- 关注开源 AI Agent 的实操部署与安全实践——Claudebot 作为 24/7 AI 员工的设置方法论、"入职培训"思维、提示注入风险隔离、模型分层使用策略
- 关注 PM 角色在 AI 时代的转型——AI 补全遗忘需求、Chat+Document 双模式产品工作流、"原型经理"取代"文档经理"、AI 原生商业模式不需要 VC
- 关注 AI 设计从通用到差异化的实战路径——结构化提示词构建器替代随意描述、模板 Remixed 替代从零开始、手动定制完成 AI 做不好的最后 10%、品味是 Vibe Coding 时代的差异化
- 关注异步 Agent 范式对非技术用户的解锁——从"等 AI 回复"到"交办任务、过会儿来看结果"的心智转换、Agent 原生架构四原则（Parity/Granularity/Composability/Emerging Capability）、Skills 作为最核心的可定制面
- 关注任务系统作为 Agent 协作基础设施——Claude Code 内置任务系统的逆向工程、跨会话持久化、多实例协作（规划者+执行者+测试者）、上下文智能作为下一个前沿
- 关注复利工程的完整实操闭环——从规划到审查到编码化学习的端到端演示、Playwright + Opus 4 的浏览器闭环测试、Commands/SubAgents/Skills 三层架构的清晰区分
- 关注 Vibe Coding 从原型到生产的全面跃迁——8小时马拉松直播揭示非技术者构建、自主循环开发、语音优先工作流、逆向工程学习法等多元范式
- 关注 Agent 作为全职员工的工程化实践——独立邮箱+身份、赞助邮件评分管线、CRM 关系智能、三层安全防御、双提示词栈模型可移植性、全量日志自愈循环
- 关注前沿模型的多维度实战评测——不是跑 benchmark 分数，而是用真实生产项目（Ruby/Swift/设计/UI）对比驾驶风格、代码组织能力、设计美学和可靠性
- 关注AI驱动的营销增长闭环——从创意验证到落地页设计、A/B测试的完整工具链实战，强调约束词策略和设计系统先行是避免vibe code感的关键杠杆
- 关注设计师用AI跨越设计-开发鸿沟——交付Draft PR替代Figma mock、代码即最高保真、CLAUDE.md个性化指令层、避免AI默认紫的锚定策略
- 关注 Andrew Ng Agent AI 课程的核心框架浓缩——Agent 自主性谱系、Evals 四象限分类（客观/主观 × 有/无逐例基准）、四种设计模式（Reflection/Tool Use/Planning/Multi-Agent），强调 Evals 是被谈论最多但实施最少的第三支柱
- 关注 OpenAI 前沿评估方法论——GDPVal 用真实经济任务替代学术基准、配对专家盲评胜率指标、评估作为前瞻性指标而非滞后指标、开发者侧 eval 产品化工具链（trace 评分、自动 prompt 优化）
- 关注 Vibe Coding 的应用全景与实践框架——七类101个AI应用方向（数据管理/硬件Agent/仪表盘/聊天助手/学习Agent/多模态/自动化）、五步构建框架（Meta Prompt→PRP→实现→调试→部署），强调需求清晰化是Vibe Coding的前提
- 关注 PM 用 AI 构建"多线程存在"——多个独立 GPT/Claude Project 作为不同场景的第二大脑（用户研究、写作教练、面试准备），Reddit 爬虫驱动无偏见用户洞察，"一切皆文本"的上下文工程方法论
- 关注 AI 微应用的选品框架——6个可复制的选品方法论（IUSR神经框架、单任务极致化、高意图输入、AI解锁高价值洞察、极简界面包装），强调从"神经"（谁的痛苦最持久）出发而非从技术能力出发
- 关注 AI 设计的提示词工程化——六维风格指南约束品牌一致性、两步式提示词结构（先提取文本再应用风格）、迭代优化后回写提示词、Gem 封装为可复用 Agent
- 关注 AI 创业的全景趋势判断——一小时公司栈、环境业务、Agent 经济时间线、垂直 AI > 垂直 SaaS 的 TAM 分析、结果定价取代座席制、稀缺翻转（执行→判断）、Founder-Agent Fit、100 真粉丝模型、Agent 安全攻击面、非对称窗口期
